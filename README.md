# QuotePlace Authors

Author biographies for QuotePlace. One file holds everything: `authors.json`.

## Format
Each entry: slug, name, born, died, role, bio (full biography), quotes (that author's quotes on the site, with text + category).

## Reading a bio
- On the web: https://cdn.jsdelivr.net/gh/QuotePlaceOrg/quoteplace-authors@main/authors.json
- Raw: https://raw.githubusercontent.com/QuotePlaceOrg/quoteplace-authors/main/authors.json

## Adding an author
1. Add one entry to `authors.json` (keep `slug` lowercase with dashes, `born`/`died` as plain years, e.g. "384 BCE").
2. Keep the bio factual and short (2-4 sentences). No invented dates or claims.
3. Add the author's quotes with their exact text and one category from the locked list: Action, Calm, Courage, Friendship, Habits, Happiness, Life, Love, Success, Wisdom.
